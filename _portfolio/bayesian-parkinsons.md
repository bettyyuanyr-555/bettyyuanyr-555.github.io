This project develops a leakage-safe 3D T1-weighted MRI pipeline for baseline de novo Parkinson's disease versus healthy control analysis.

The approach combines shared-weight bilateral representation learning, an HC-only symmetry constraint, and an explicit target-prevalence prior for class-conditional Bayesian posterior risk. Planned evaluation includes calibration, bootstrap uncertainty, site stability, and sensitivity analyses.

**Status:** Manuscript in preparation.
